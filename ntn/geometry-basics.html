HOW TO READ THE GEOMETRY

O · 地心定义地心坐标与地球半径 Rₑ。
P · 星下点卫星沿地心法向投到地表的位置。
B · 波位中心波束指向的地表目标，可以偏离 P。
U · UE实际链路的接收位置，可以偏离 B。

建模平面与坐标定义

UV 名称需连同定义一起看：方向余弦 UV 表示发射方向；中兴 6870 附录的 U、V 表示归一化经纬位置。同名坐标的原点、物理含义与间距公式分别定义。

UE ELEVATION / SPHERICAL GEOMETRY

UE 仰角与服务区域最低仰角

仰角 ε 在 UE 处测量，是“UE 指向卫星的连线”与“UE 当地水平面”的夹角。已知卫星位置和 UE 位置，就可以直接计算；确定整个服务区域后，再寻找其中仰角最低的位置。

1. 单个 UE 的通用三维计算

设地心为 O，卫星位置为 S，UE 位置为 U，位置向量采用同一地心坐标系。球形地球上，UE 的当地天顶单位向量为 nᵤ=U/‖U‖，星地斜距为 d=‖S−U‖。

ε(U,S) = asin[ ((S−U)·nᵤ) / ‖S−U‖ ]
ε > 0°：卫星在当地地平线以上；ε = 90°：卫星在 UE 正上方。

该式适用于单星或多星的每一条链路。采用椭球地球时，nᵤ 改用 UE 处的椭球法线；以下计算统一取球形地球 Rₑ=6371 km、地面 UE 高度为 0。

2. 从地表距离展开计算

步骤在哪计算计算式与含义
① 地表距离 → 地心角地心 O 处的 ∠POUP 为该卫星星下点；若 P 到 U 的大圆弧长为 L，则 ψ=L/Rₑ，单位 rad。
② 星地连线 → 当地分量以 UE 为原点的天顶 / 水平坐标竖直分量 z=(Rₑ+h)cosψ−Rₑ；水平分量 t=(Rₑ+h)sinψ。
③ 当地分量 → 仰角UE 处的当地水平面ε=atan2(z,t)；d=√(z²+t²)。atan2 保留正负号，可识别地平线以下的卫星。

3. 从单点仰角得到区域最低仰角

对固定高度、固定服务卫星，仰角随星下点到 UE 的地心角增大而降低。因此，先在实际服务区域 𝒜 内找到距星下点最远的位置，再代入上式。

Lₘₐₓ = maxU∈𝒜 Rₑ·acos[(P·U)/Rₑ²]
εₘᵢₙ = atan2[(Rₑ+h)cos(Lₘₐₓ/Rₑ)−Rₑ, (Rₑ+h)sin(Lₘₐₓ/Rₑ)]

多星场景先确定各 UE 的服务星 s(U)，再求 minU∈𝒜 ε(U,s(U))。若采用最高仰角选星，则 εserv(U)=maxk∈候选服务星 ε(U,Sₖ)；采用接收功率选星时，应使用最终选中的服务星重新计算。

计算范围：波位中心最小值、随机 UE 样本最小值、连续服务区域最小值分别计算。要评价区域边缘，应检查实际地面边界；六角逻辑区域映到球面后，边界形状取决于所用映射。预设的最低服务仰角是设计输入，布局生成后的实际最低仰角是几何计算结果。

4. 高通布局示例：约 28.33° 的来源

沿用本页高通演示的具体实现：h=600 km，逻辑宽小区中心距 D=200 km，中心外 n=4 圈；将逻辑平面的径向距离映成球面弧长。最远小区中心距为 nD=800 km，但服务区域还包括外侧顶点。最远顶点可取 (x,y)=((n+½)D,D/(2√3))。

Lₘₐₓ = D√[(n+½)²+1/12] = 901.85 km
ψ = 8.1105°；εₘᵢₙ = 28.33°
