STEP 01 / SINGLE-SATELLITE LAYOUT

第一大步 · 确定单星布局

方向余弦平面（Direction-cosine Plane，UV 平面）记录卫星看向地面的方向。小米先固定这张方向网格，再把每个方向与地球表面相交。地面中心间距与足迹形状由卫星位置和地球曲率共同决定。

本步输出：中心星位置、单星 UV 波束集合、地面足迹与边缘波束。下一大步据此确定卫星间隔。

1.1 中心星、局部坐标与波束方向

中心星在纬度–经度–高度坐标系（Latitude, Longitude, Altitude，LLA）中设为 (0°,0°,h)。在地心地固坐标系（Earth-Centered, Earth-Fixed，ECEF）中，其星下方向指向地心；局部 u、v 轴分别取东向、北向。

S = (R+h)[cosφ cosλ, cosφ sinλ, sinφ]
d(u,v) = u·eE + v·eN − √(1−u²−v²)·eR

φ 为纬度，λ 为经度；eR 是星下点的外法向，eE、eN 是东向、北向单位向量。u、v 无量纲，(0,0) 对应星下方向。每颗邻星都有自己的局部坐标基。

原文定位：R1-2607227，SLS methodology and assumptions → Reference constellation parameters，Steps 1–2、Table 1。

1.2 UV 网格、层数与束数

中心层只有 1 束，第 k 个外圈有 6k 束。原文的 5 层包含中心层，因此外圈数为 4；13 层对应 12 个外圈。

n = L−1
M = 1 + 6(1+2+…+n) = 1+3L(L−1)
L=5 → M=61　　L=13 → M=469

六边形中心按轴坐标 (q,r) 编号：u=s(q+r/2)，v=3ρr/2，其中相邻中心距 s=√3ρ。先确定每条波束的 UV 方向，再计算地面足迹。

固定层数后，每星配置波束数已经确定。修改 UV 间距会改变覆盖尺度；修改层数会同时改变束数与覆盖范围。

原文定位：Figure 1（13 tiers, 469 beams）、Figure 3 / Table 1（5 tiers, 61 beams per satellite）。

1.3 从 UV 方向到球面交点

从卫星 S 沿方向 d 发出射线 P(t)=S+t·d。求它与半径为 R 的球面第一次相交的位置，便得到地面波束中心；对六边形边界逐点计算，则得到地面足迹。

t = −S·d − √[(S·d)² − (‖S‖²−R²)]
P = S + t·d

t 的单位为 km。根号内小于 0，表示该方向未击中地球。偏离星下方向越远，地面映射通常拉伸越明显；这正是 Figure 1 的 469 束布局出现外缘形变的来源。

UV 六边形是网格的几何分区。实际天线功率轮廓还由阵列权重、扫描方向与方向图决定。

原文定位：Steps 3、6，Figures 1–3；本页射线求交式为该映射的球形地球实现。

1.4 小米选择 UV 网格的原因

小米比较了地面等尺寸布局与 UV 布局。地面等尺寸布局便于规划服务区域，但固定全阵列时，不同仰角处的中心到边缘增益差会变化；若再保持固定 3 dB 边缘，需要研究波束形成或阵元使用方式。

小米倾向复用 UV 布局，强调其与固定阵列角域响应的对应关系，并接受地面分布不均匀这一结果。原文关于边缘增益的比较属于该天线与布局假设下的公司观点。

原文定位：Observations 1–3、Proposal 3、Table 2。页面几何映射未加入扫描损耗或功率方向图。

STEP 02 / SATELLITE POSITIONS

第二大步 · 确定多星中各卫星的位置

中心星的足迹生成后，小米用北侧边缘的一处参考点确定邻星间隔。原文的动机是减少星间波束重叠、避免区域覆盖孔洞；这个边缘关系把“单星覆盖多大”与“卫星彼此离多远”连接起来。

本步输入：单星边缘波束。输出：七星 LLA / ECEF 位置，以及各星复用后的完整波束布局。

2.1 从单星边缘读取 Δ

橙色 P：原文选取的参考点；C：北侧边缘波束中心；N：中心波束中心。名义半径 r=D/2，本页向北偏移 r/4。

Δ 的逐步计算

先从已经落到地面的布局中找到正北方向的边缘波束中心 C，再从 C 向北偏移四分之一波束半径，得到参考点 P。中心波束中心 N 与 P 的纬差定义为 Δ。

Δ 是在地心处量取的角度。北侧邻星的星下点放在 2Δ 处，P 的纬度恰好位于两个星下点纬度的中间。侧方邻星按 ±Δ、±√3Δ 组合布置。

原文的 r/4 参考点位于边缘波束内部，通常不等于整个足迹的最北顶点。动态图把两者分别标出，避免把 Δ 理解成最远 UE 的纬度。

原文定位：Figure 2 前的地心角定义段落，以及相邻卫星 LLA 坐标示例。图中“edge of coverage”的宽泛标注与正文 r/4 的具体构造分别保留。

3.2 建立干扰集合与计算规模

Annex A 设置每束均匀分布 10 个 UE，因此七星共 7×61×10=4270 个 UE。对某一服务波束的 10 个 UE，逐一遍历 426 个干扰束，对应 4260 次候选链路计算。

单个 UE：426 条潜在干扰链路
单个服务束的 10 UE：10×426=4260 次
全场 4270 UE：4270×426=1,819,020 次

最后一项是一次全量遍历的规模估算。实际同频、可见与调度后的活动集合会更小。若只统计中心星，仍可保留邻星波束的干扰贡献。

原文定位：Interference simulation 第一段、Table A-1。1,819,020 为上述输入的乘法推导；原文“4260 links”对应每束 10 UE 的展开。

3.3 逐链路算接收功率，再求和

每条候选链路使用其发射卫星的真实位置，以及该卫星中这条波束的指向。先检查可见性、频率与活动状态，再按路径损耗及收发天线增益计算接收功率。

Pi→u = Ptx,i × Gtx,i(u) × Grx,u(i) / Li,u
Iu = Σ ai(t,f) · χi,u(f) · Pi→u
SIR = Pserving/Iu　　SINR = Pserving/(Iu+Nu)

这里所有功率与增益采用线性值。a 表示时频活动状态，χ 表示是否同频；L 包含所选传播模型的损耗。页面上方显示的是几何候选集合，不把束数转换成 SIR。

原文定位：Interference simulation of multi-satellites、Annex A / Table A-1；功率计算式是工程展开。

交互图采用的具体实现

球形地球 R=6371 km；u 取东、v 取北。网格采用点顶六边形：中心距 s=√3ρ，中心 (u,v)=(s(q+r/2),3ρr/2)，且 max(|q|,|r|,|q+r|)≤L−1。边界采样后逐点射线求交。

UV 半径 ρ 用星下点名义束半径 D/2 对应的球面方向标定。提案 Table A-1 给出 50 km 名义直径，并另写 IBD 依据天线 3 dB 宽度计算；本页标定便于观察几何，不作为原文方向图与间距的精确重现。

Δ 的 r/4 偏移沿北向子午线实施，其中 r=D/2；北侧正向参考点取 0.25r。FRF=3 使用 (q−r) mod 3，跨星同标签同频；这套颜色相位为页面设置。改变层数、尺寸或高度属于几何敏感性实验。页面不生成新的 SIR / SINR 曲线。
