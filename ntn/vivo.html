1.1 / 在 O–S–B 三角形内换算

角度标尺 → 地表弧长

Δuv = √3 sin(HPBW / 2)
θsat = asin(Δuv)
θearth = asin[(1+h/Rₑ) sin θsat] − θsat
d = Rₑ θearth

取近侧地表交点。这里的相邻点是星下点 N 与偏离天底 θsat 的地表点 B，得到星下点附近的基准 d；随后用同一个 d 生成球面网格。角度统一使用弧度。

1.2 / 在 OAₙBₙ 平面内等分地心角

Aₙ → Cₙᵢ → Bₙ

沿相差 60° 的两条大圆方向，各走 n·d，得到 Aₙ、Bₙ。将 ∠AₙOBₙ 等分为 n 份，每条边放 n 个不重复节点。

αₙ = n·d / Rₑ
βₙ = acos(a · b), f = i/n
C/Rₑ = [sin((1−f)βₙ) a
　　　　+ sin(fβₙ) b] / sin βₙ

这里 a、b 为端点单位向量。球面线性插值（Spherical Linear Interpolation，SLERP）直接给出 C，等价于原稿“弦上求 K → 沿 OK 投到球面”。等分的是地心角，不是把弦长直接等分。

径向相邻环角点的弧长是 d；本环同一条大圆边上的间距是 Rₑβₙ/n。二者因球面曲率略有差异，“近似均匀”不等于所有中心间距严格相等。
1.3 / 球面中心 → 每颗星自己的波束轴

UV 坐标在这里怎样出现？

给定卫星 S 和球面中心 C，先计算单位轴线 ℓ=(C−S)/‖C−S‖，再向卫星局部横向基投影，得到 u、v。相同地面 C 对不同卫星通常具有不同 UV；本方法生成的球面中心也不对应严格等间距的 UV 网格。

u = ℓ·êeast，v = ℓ·ênorth，w = ℓ·n̂nadir
u²+v²+w²=1；u、v 无量纲，d 的单位是 km

2.1 / 切平面内的六边形拼接

为什么出现 √3？

Rhex = t·d
rin = (√3/2)Rhex
D = 2rin = √3·t·d

先在平面六角拼接中得到标尺 D，再把长度 D 交给指数映射，使参考星下点到每个邻星下点的地表弧长等于 D。D 不是两颗卫星的三维直线距离。

√3 来自平面拼接。指数映射保持的是 P₀ 到每个 Pₖ 的径向大圆距离，不保证球面任意两点的距离全部保持；是否完全无缝、无洞，还需结合实际足迹检查。
2.2 / 球面上沿大圆走 D

切平面点如何变成卫星坐标？

参考星下点单位法向为 n̂，切向基为 êeast、ênorth。六个方向相差 60°，错位后为 ψₖ=kπ/3+δ。

t̂ₖ = cos ψₖ êeast + sin ψₖ ênorth
γ = D/Rₑ
Pₖ = Rₑ(n̂ cosγ + t̂ₖ sinγ)
Sₖ = (Rₑ+h) Pₖ/Rₑ
δ = ρ·d / D

指数映射不是“沿地心射线把 Qₖ 缩放到球面”，也不是沿法向向下投影。前者会给出弧长 Rₑ·atan(D/Rₑ)，而这里要求弧长恰为 D。Pₖ 确定后，才沿各自地心法向抬高 h。

每颗邻星在自己的星下点附近重新放置同一球面中心模板，再由自己的卫星位置指向它们。本页将参考切向基平行运输到各邻星以确定朝向；这是向量实现补充，不是把参考星的 UV 数值直接平移给邻星。

“三轨道七星”怎样理解？

Proposal 17 建议三轨道、中心加六邻星的基线；Step 3 用六个切向方位直接生成局部七星位置。要进一步计算卫星随时间的运动，需补入各轨道面的倾角、升交点赤经、卫星相位与历元，再检查相对位置如何变化。当前交互计算的是位置快照，改变纬度会旋转这套局部布局。

3.1 / 统计集合

397 个候选波位中，270 个用于选统计 UE

感兴趣区域（Region of Interest，ROI）在原稿统计例中取第 7–11 环。UE 的服务波束属于这 270 个波位时，其 SIR 才进入统计；270 是波位数，实际 UE 样本数还取决于每波位撒点数和快照数。缓冲区样本提供干扰。

minᵢ∈ROI arc(Cⱼ,Cᵢ) ≤ b·d
arc(a,b) = Rₑ acos(â·b̂)

对六颗邻星逐一枚举波位，满足上述判据的中心才进入候选信道集合。2 环缓冲表示距离阈值 2d，不是“保留邻星的两环”，也不是再加入两圈卫星。本页同时用该距离规则保留已有网格中的本星缓冲波位。

本页的候选网格为每星 0–t 环；缓冲只筛已有点。若实现需要延伸网格，须先生成扩展中心，再应用相同筛选规则。

3.2 / 对同一个 UE 逐链路相加

统计范围与干扰范围分开

SIRsingle = Ps / Iintra
SIRmulti = Ps / (Iintra + Iinter)
下降量 = 10log₁₀(1+Iinter/Iintra)

用户设备（User Equipment，UE）连接一颗服务星。固定同一个 UE，分别沿服务链路与各候选干扰链路求接收功率：先应用同频资源与活动掩码，再把功率转为线性量求和。下行每条链路都使用该发射卫星到 UE 的斜距及该波束的离轴角。

Pₖᵦ→U = Ptx,ₖᵦ · Gtx,ₖᵦ(U) · Grx,U(Sₖ) / LₖU
Iintra = Σ 本星其他同频活动束 P₀ᵦ→U
Iinter = Σ 六邻星同频活动束 Pₖᵦ→U

下行的干扰发射源是活动卫星波束；上行的干扰发射源是其他 UE。原稿保留缓冲 UE 的处理在上行直接对应干扰发射用户。

3.3 / 从单个 UE 走到 CDF

每个快照按同一条计算链执行

  1. 形成样本：按 UE 撒点与关联规则生成位置，标记服务波束属于 ROI 的统计样本；同时保留缓冲干扰源。
  2. 形成活动集合：按每星活动波束上限及激活策略点亮候选波位，确定同频资源。32 只限定数量，仍需给出哪些波位在何时活动。
  3. 计算逐链路功率：用同一 UE 的服务与干扰链路计算增益、损耗和接收功率，分别累加 Iintra、Iinter。
  4. 配对比较：对固定 UE、服务束和活动快照，同时计算是否计入邻星时的 SIR，使差异对应新增星间干扰。
  5. 统计分布：对更多 UE 与快照重复，收集 ROI UE 的 SIR；经验 CDF 为 F̂(x)=满足 SIR≤x 的样本数 / 总样本数。汇总时记录每波位样本数及权重。
