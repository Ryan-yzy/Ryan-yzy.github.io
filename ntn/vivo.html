GROUND FIRST

01 / 把波束中心铺到地球表面

HPBW 先给出星下点附近的间距标尺；再以地表弧长为尺度，生成一圈圈球面节点。

单星球面网格 · 地表俯视
其他环所选环分点 C点表示波位中心，轮廓连接最外环中心
1.1 / 在 O–S–B 三角形内换算

角度标尺 → 地表弧长

Δuv = √3 sin(HPBW / 2)
θsat = asin(Δuv)
θearth = asin[(1+h/Rₑ) sin θsat] − θsat
d = Rₑ θearth

取近侧地表交点。d 是相邻中心的基准弧长，角度计算统一使用弧度。

1.2 / 在球面扇区内补点

Aₙ → Cₙᵢ → Bₙ

沿相差 60° 的两条大圆方向，各走 n·d，得到 Aₙ、Bₙ。将 ∠AₙOBₙ 等分为 n 份，每条边放 n 个不重复节点。

αₙ = n·d / Rₑ
βₙ = acos(a · b), f = i/n
C/Rₑ = [sin((1−f)βₙ) a
　　　　+ sin(fβₙ) b] / sin βₙ

这里 a、b 为端点单位向量。球面线性插值（Spherical Linear Interpolation，SLERP）等价于原稿的 K 点定方向、径向投影到 C 点。

每环 6n 个节点，总数 N=1+3t(t+1)。球面局部六边形构造的各方向间距会随曲率略有变化。

02 / 用网格尺度确定七星位置

相邻六边形中心相隔两倍内切半径。先在参考星下点的切平面定方向，再沿大圆弧走到邻星下点。

七星地表网格 · 参考点等距投影

2.1 / 切平面内的六边形拼接

为什么出现 √3？

Rhex = t·d
rin = (√3/2)Rhex
D = 2rin = √3·t·d

这里 D 是星下点间的地表弧长。高度与波束宽度决定 d；环数决定网格尺度，二者共同决定邻星间距。

原稿以此构造连续覆盖布局。地表中心网格确定后，实际足迹重叠和覆盖仍可按波束方向图进一步检查。
2.2 / 球面上沿大圆走 D

切平面点如何变成卫星坐标？

参考星下点单位法向为 n̂，切向基为 êeast、ênorth。六个方向相差 60°，错位后为 ψₖ=kπ/3+δ。

t̂ₖ = cos ψₖ êeast + sin ψₖ ênorth
γ = D/Rₑ
Pₖ = Rₑ(n̂ cosγ + t̂ₖ sinγ)
Sₖ = (Rₑ+h) Pₖ/Rₑ
δ = ρ·d / D

指数映射让每个 Pₖ 位于地球球面，且到参考星下点的弧长等于 D。随后沿各自地心法向抬高 h。

本页将参考切向基平行运输到各邻星，以保持复制网格的朝向。这是原稿步骤的向量实现补充。

“三轨道七星”怎样理解？

Proposal 17 建议三轨道、中心加六邻星的基线。Step 3 给出的是局部七星位置快照；倾角、升交点赤经与轨道相位需在动态星座建模时另行指定。切换纬度展示同一局部构造在不同位置的建立方式。

外侧五环为何是 270？

统计时只保留服务波束属于 ROI 的 UE。本星其余保留区域可以提供干扰，邻星也通过缓冲判据参与干扰计算。

minᵢ∈ROI arc(Cⱼ,Cᵢ) ≤ b·d
arc(a,b) = Rₑ acos(â·b̂)
