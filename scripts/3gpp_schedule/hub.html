RAN 会议日程北京时间 · UTC+8

分别查看 RAN1、RAN2、RAN3、RAN4 的完整议程、课题目录与并行会场安排。按原会议日结构浏览，所有表内时间均已换算为北京时间，跨午夜明确标注“次日”。

来源说明

会议安排来自 Duckhyun Bae 维护的 3GPPSchedule 原始日程 ↗：RAN1 · RAN2 · RAN3 · RAN4。本页增加北京时间换算、分组浏览与个人参会计划导出。

如何关注并导出
  1. 选择会议进入 RAN1—RAN4，按日期或课题筛选。想选整周，先点“全部会议日”。
  2. 点 ☆ 关注列表点星标，或点开时间表中的会议后选“加入我的关注”；也可用“关注当前筛选”批量选择。
  3. 导出关注点“导出关注” → 选“我的关注 · 跨 RAN1—RAN4” → 选择 Excel 或日历图 PNG 等格式 → 下载。

关注保存在当前浏览器；各工作组可合并导出，换设备或浏览器需重新选择。日历图适合保存与分享；日历 ICS 可导入日历应用。

导出我的关注议程

先在任一工作组页面点 ☆ 关注场次，再将 RAN1—RAN4 的关注合并导出为 Excel、日历图 PNG、Markdown、CSV 或日历 ICS。关注保存在当前浏览器。

__HUB_CARDS__

北京时间 = 卡尔加里当地时间 +14 小时。当地周一 09:00 → 北京时间周一 23:00；当地周一 14:00 → 北京时间周二 04:00。

各页面支持时间表 / 列表、日期切换、课题目录、搜索、会场筛选、星标关注和个人议程导出（Excel / PNG / Markdown / CSV / ICS）。
RAN2 周四的 Breakout 3 以及 RAN4 各日期的会场名称均已保留。
